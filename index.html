操作手順
① まずホーム画面に追加してください（必須）。iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android Chrome はメニュー →「アプリをインストール」。ホーム画面追加していないと業務開始ボタンが押せません。
② 下の「設定」タブ →「料金設定」で、初乗り料金・初乗り距離・加算料金・加算距離を入力してください。同じ画面の「追加料金」タブで迎車料金・高速料金などの項目も登録できます。
初回起動時に画面中央の青い「センサーを許可する」ボタンを押してください。iPhone はコンパス・加速度・位置情報の許可ダイアログが順番に出るので全て「許可」を選びます。Android は自動許可で位置情報のダイアログのみ出るので「許可」を選びます。許可が完了すると上部の GPS バッジが「GPS待機」→「精度Xm」に変わります。
許可完了後に表示される青い「業務開始」ボタンを押します。一日の業務スタート（GPS 起動・画面消灯防止・集計値 0 リセット）が走り、空車画面に遷移します。お客様を乗せる時は空車画面の「代行開始」ボタンを押すと走行距離・料金がリアルタイム計算されます。目的地で「確定」→ 料金画面（内訳表示）→「空車」を押して 1 trip 確定です。
実車中の画面上部に並ぶ「割増」ボタン群を ON / OFF できます。複数同時に ON にすると倍率は掛け算（深夜×1.2 + 悪天候×1.1 = 1.32 倍）。深夜・週末・冬季の自動割増は時刻 / 曜日 / 日付で自動判定し対象時間に入ると勝手に適用されます。割増ボタンの追加・編集は「設定」→「料金設定」→「割増」または「自動割増」タブから。
実車中の「追加料金」ボタンを押すと項目選択モーダルが出ます。迎車料金・高速料金・キャンセル料など登録済の項目をタップで即加算。同じ項目をタップした回数だけ累計されます（例: 高速料金 ¥1,000 を 3 回タップで合計 ¥3,000）。項目自体の追加・編集は「設定」→「料金設定」→「追加料金」タブから自由にできます。
空車画面の「業務終了」ボタンを押します。確認ダイアログが出るので「OK」で日報画面に遷移。日報画面では「続ける」（業務を再開して空車画面に戻る）と「終了」（業務開始画面に戻る）の 2 択。「終了」を押した後の業務開始画面には「業務再開」ボタンが残り、いつでもその業務を再開できます（時間制限はありません）。完全に新しい業務を始めたい場合は「業務開始」を押すと集計値が 0 リセットされます。
下の「履歴」タブ、または空車画面の「履歴」ボタンから、当日の trip 一覧を確認できます。各行に開始時刻・走行距離・料金・追加料金の内訳が表示され、上部に「走行回数」「総距離」「総売上」の集計も出ます。表示は当日分のみで、日付が変わると新しい 1 日になります。
よくある質問
iPhone は「設定」アプリ → ダイコメ → 位置情報 →「常に」を選択。Android は「設定」アプリ → アプリ → ダイコメ → 権限 → 位置情報 →「常に許可」を選択。設定変更後、ダイコメに戻ると GPS バッジが 「GPS待機」→「精度Xm」に変わります。
業務中にタスクキルされた場合、再起動すると自動的に直前の状態（実車中・走行距離・料金・追加料金・総走行距離）に復元されます。iPhone は再起動後にオレンジバナーが出るので「センサーを再起動する」ボタンを 1 回押せば GPS / コンパス / 加速度が復活し、計測が続行します。時間制限はないため、長時間後の復元でも引き継げます。
使えます。47 都道府県の道路データは初回起動時に端末内に保存されるので、地下・トンネル・電波の届かない場所でも料金計算（道路に沿った距離計算）は継続します。Firebase への送信は復活時にまとめて再送されます。
「設定」タブ →「料金設定」→「追加料金」タブで、項目の名前と金額を自由に追加・編集・削除できます。実車中の「追加料金」モーダルに即時反映されます。
「設定」タブ →「料金設定」→「割増」タブで、手動割増ボタンを追加できます。名前・倍率・色を自由に設定でき、複数 ON で倍率は掛け算されます。深夜・週末・冬季の時刻ベース割増は「自動割増」タブから ON / OFF と倍率設定が可能です。
「設定」→「料金設定」→「基本」タブで、初乗り料金・初乗り距離・加算料金・加算距離が正しく入っているか確認してください。0 や空欄のままだと加算料金がカウントされません。設定変更後は「保存」ボタンを必ず押してください。
業務終了 →「終了」を押すと業務開始画面に戻りますが、画面に「前回の業務を引き継ぐ場合は」の赤い注釈と「業務再開」ボタンが残ります。これは前の業務を再開する経路です（時間制限なし）。完全に新しい業務として始めたい場合は「業務開始」を押してください（集計値が 0 リセット）。

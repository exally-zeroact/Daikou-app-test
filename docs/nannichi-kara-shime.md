# 締め日（明細の期間の払い方）を「何日から」で変える（設計 v1・2026-10-19）

司さんの決め（10-17・人・役割・売上の何日からと同じ）：
- 変える日は使う人が選ぶ（既定は今日・過去も先も）。その日から次の変更の日までその値。その日より前は前の値。
- 過去の日を選んだら、その日から後は遡って新しい区切り（給料・月次・紙・本人の明細）。締めて払った期でも止めない。

## 計算（区切りの1か所は PayrollPeriod のまま）
- `PayrollPeriod.rirekiKata(kata, rows)`：
  - rows が undefined＝記録無し＝kata そのまま（今と1円・1日も違わない）。
  - kata が dame＝dame のまま。rows が null／配列でない＝dame（tsushin＝読めなかった）。
  - 1行でも日付の形が違う・seiki が通らない＝dame（訳は「締めの 変えた 記録が 読めません」）。
  - 日付順に並べ、[列の形, 記録1, 記録2…] の区間に組む。★隣と同じ形は1つにまとめる★（同じ形の記録で期を切らない）。区間が1つ＝kata そのもの。
  - 2つ以上＝`{kind:'rireki', segs:[{kara:'', kata}, {kara:'2026-10-05', kata}, …]}`。
- `periodsOf(y, m, {kata})` は kind 'rireki' の時：
  - 区間ごとに、その形の素の期（前後3か月）を作り、区間の [kara, 次の kara − 1] で切る。
  - ★変えた日 D の前日で必ず切れる★。切った期は短くなる（印 kiri:true）。前の形と新しい形の両方で D が区切りの時だけ短い期は出ない。
  - 何月分か（★司さんの決め 10-19・2回★）：
    - 前の形の側（後ろを切った期）＝★元の期の月のまま★。例：20日締め（締めた日の月の分）を 10/1 から末日締めへ＝9/21〜9/30 は元の 9/21〜10/20 と同じ 10月分・10/1〜10/31 も 10月分。
    - 新しい形の側（頭を切った期）＝★切った後の日付で★その形の nazuke の通り。例：末日締めを 10/15 から 20日締め（始まった日の月の分）へ＝10/15〜10/20 は 10月分（元の 9/21〜10/20 の 9月分に入れない＝払い終えた月に後から日を入れない）。
    - 試験：どの期も始まりの日の月より前の月の分にならない（乱数の歴 200通り）。
  - その月の分だけを日付順に返す。名前・rangeLabel の付け方は今の kataPeriods と同じ。
- ★性質の試験★：ばらばらの記録を入れた歴で、どの日もちょうど1つの期に入り、1つの期はちょうど1つの月の分。
- `PayrollPeriod.tsukiNoKata(kata, y, m)`：その月の期が全部1つの区間から切られずに出る時はその形・他は null。
  - kyuryo：月3回なら最初の期（今の通り）・他は今日を含む期。毎日払い（紙で期の列を出さない）も月の形で見る。
  - getsuji：out.kind はその月の形（混ざる月は 'rireki'）。年の「期ごとの合計」は、全部の月の形が同じ時だけ（形が変わった年は出さない＝違う区切りの n 回目を同じ列に足さない）。
- `PayrollPeriod.kataNoHi(kata, 日)`：その日に効く形（画面の欄に出す）。
- payroll-daily normSettings(row, shimeRows)：yomu(row) の形に rirekiKata(…, shimeRows) を重ねる。buildCtx は raw.shimeRireki を渡す。

## 画面（給料の設定 → 明細の期間）
- 払い方の上に「何日から」（既定は今日＝JST・空＝最初から＝今と同じく列を直す）。
- 欄には ★選んだ日に効く形★。日付を変えたら出し直す。
- 「区切り …」の字は、選んだ日から今の欄の形にした時の本当の区切り（切り替わりの短い期も出る）。
- 保存する：
  - 日付が空＝今と同じ（列 period_shime / period_end_mode を書く）。
  - 日付が在る＝列の締めは読んだままの値を運ぶ（変えない）。欄の形が選んだ日に効く形と違えば、設定を保存できた後に dk_shime_rireki へ書く（on_conflict=company_id,from_date＝同じ日が在れば直す）。書けなければ「締めは 保存できませんでした（他は 保存しました）」。
- 記録が読めない時・設定が読めない時は保存させない（今の SET.yomenai と同じ）。
- 「記録 N」：日付順に、日付（直せる）・形の字・消す。形を直す時は「何日から」にその日を入れて選び直し保存。
- 記録の在る会社で日付を空にした時は「空は 最初の 記録（◯）より 前の 日だけ 変わります」。

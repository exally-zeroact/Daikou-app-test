### ★追加2 — 入った1行の「中身」を照合する★

行が増えただけでは足りない。**メーターの確定値とファイルの中身が一致しているか**を1項目ずつ見る。

| 見る所 | 照合相手 |
|---|---|
| `date`（日付） | 代行した日 |
| `company`（会社名） | テスト建設（消してよい） |
| **`amount`（金額）** | ★**メーターの確定値そのものか**★ |
| `destination`（行き先） | 実際の到着地 |
| `distance`（km・小数1桁） | メーターの `distance_m` ÷1000 |
| `extra.dk_from`（出発地） | 実際の出発地 |

★**金額が1円でもズレていたら、そこで止めて報告**★。「入った＝合っている」ではない。
